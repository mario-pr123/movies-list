# Octubre de Terror — app web instalable (PWA)

Archivos: `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`. No necesita servidor ni base de datos.

## 1. Publicarla (una sola vez)
Opción Vercel (como tu web de citas):
1. Crea un repositorio en GitHub y sube el contenido de esta carpeta (en github.com → New repository → "uploading an existing file" → arrastra los archivos y la carpeta icons).
2. En vercel.com → Add New → Project → importa ese repositorio → Deploy (sin configurar nada: es un sitio estático).
3. Te dará una URL tipo `octubre-terror.vercel.app`.

## 2. Instalarla en cada iPhone
Abre la URL en **Safari** → botón Compartir → **Añadir a pantalla de inicio**. Ábrela siempre desde ese ícono.

## 3. Cómo se usa
1. Cada uno escribe su nombre y arma su lista (hasta 31). Con la ⭐ marca sus 15 elegidas.
2. Sagas: pon el mismo nombre de saga y el número de parte (Saw 1, Saw 2…). Funciona aunque cada parte la haya puesto una persona distinta.
3. Mi lista → "Compartir mi código" → mándalo por WhatsApp. La otra persona lo pega en Pareja → Importar.
4. Uno de los dos va a Calendario → "Generar calendario" → "Compartir calendario". La otra persona importa ese código y los dos quedan con el mismo mes.
5. 15 + 15 = 30 pelis; la noche 31 (y cualquier hueco) se rellena con un "comodín" sacado de las pelis no elegidas.
6. Toca un día para marcarlo como visto o intercambiarlo con otro.

Los datos viven en cada iPhone. Para sincronizar, vuelvan a compartirse el código.
